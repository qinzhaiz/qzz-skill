# qzz-skill

> 面向学习者的中文 AI Skills 工具箱。把技术概念和领域学习交给 Agent，获得结构化的讲解和可执行的学习路线。

**支持：Claude Code 以及其他支持 Skills 的 Agent。**

[快速开始](#快速开始) · [技能一览](#技能一览) · [安装](#安装) · [知识库](#知识库)

## qzz-skill 解决什么问题

你不用先判断自己需要什么——把想学的东西、卡住的概念直接抛出来，它会选择合适的方式回应。

| 真实处境 | 你会得到 |
| --- | --- |
| 看了五篇文章都没搞懂一个概念 | 从设计动机出发的阶梯式讲解，找到让你"click"的那个类比 |
| 想学一个领域，不知道从哪开始 | 依赖图驱动的学习路线，先学什么后学什么一目了然 |
| 反复卡在同一个概念上 | 定位误解根源，精准修正，不重讲你已经懂的部分 |
| 准备面试、做练习、查文档 | 结构化知识库：正文 + 示例 + 练习 + 面试题 |
| 不知道学到什么程度算"会了" | 每个阶段有可验证的自查标准 |

## 快速开始

安装完成后，直接说：

```text
什么是 MySQL 的覆盖索引？
```

qzz 会自动判断：知识库里有这个内容 → 直接查阅；需要深讲 → 调用 qzz-explain。

```text
我想系统学 MySQL，给我一个学习路线
```

qzz 会调用 qzz-roadmap 生成路线图，同时标注知识库中已有的章节。

## 技能一览

| 技能 | 做什么 | 触发方式 |
|------|--------|---------|
| **qzz** | 入口路由，自动分流到合适的子技能 | 直接问问题就行 |
| **qzz-explain** | 三模式概念讲解（速览 / 深讲 / 纠错） | "解释一下 X""怎么理解 X" |
| **qzz-roadmap** | 生成结构化学习路线 + 依赖图 | "我想学 X""X 的学习路线" |
| **qzz-mysql** | MySQL 知识库：17 章 71 个概念 | 自动引用，用户不需手动调用 |
| **qzz-practice** | 交互式练习：编程题、选择题、填空题 | "出几道题""来个测验""做个题" |

## 安装

一条命令安装全部 5 个技能：

```bash
npx skills add qinzhaiz/qzz-skill --all
```

也可以挑着装：

```bash
npx skills add qinzhaiz/qzz-skill --skill qzz --skill qzz-mysql
```

### 更新

```bash
npx skills update qzz-skill
```

## 知识库

`qzz-mysql` 包含完整的 MySQL 8.0 学习资料：17 章 71 个概念，从零基础到阅读源码。每个概念 7 个文件：正文、示例、练习、常见错误、面试题、参考资料。
