# 使用示例

## 生成 MySQL 学习路线

**用户**：我想系统学 MySQL，零基础，目标是能干活+面试。

**qzz-roadmap**：

---

📚 **学习路线：MySQL（零基础 → 能干活 + 面试）**

🎯 目标画像：完成这条路线后，你能独立设计数据库表结构、写出高效 SQL、理解索引和事务原理、通过初中级后端开发面试的数据库部分。

📋 前置条件：会用电脑即可，不需要编程基础。

---

🏔️ **阶段一：会写 SQL**（预计 2 周）

- 🔴 必学：数据库是什么 → 安装 MySQL → 第一条 SELECT → WHERE 过滤 → 排序分页
- 🔴 必学：建表（CREATE TABLE）→ 数据类型 → INSERT/UPDATE/DELETE
- 🔴 必学：JOIN 连接查询 → GROUP BY 分组统计
- 🟡 选学：子查询、UNION
- ✅ 验证：给一个电商场景描述，能在 30 分钟内建 5 张表并写出 10 条常用查询
- 📖 资源：`knowledge/01-basic/`、`knowledge/02-ddl/`、`knowledge/03-dml/`、`knowledge/04-query/`

---

🏔️ **阶段二：理解索引和性能**（预计 3 周）

- 🔴 必学：什么是索引 → B+Tree 原理 → 聚簇索引 vs 二级索引
- 🔴 必学：联合索引 → 最左前缀 → 覆盖索引
- 🔴 必学：EXPLAIN 执行计划 → 慢查询日志 → 常见 SQL 优化模式
- 🟡 选学：函数和存储过程
- ✅ 验证：给一条慢查询，能说出它为什么慢、怎么建索引优化、优化后 EXPLAIN 显示什么
- 📖 资源：`knowledge/06-index/`、`knowledge/10-performance/`

---

🏔️ **阶段三：事务与锁**（预计 2 周）

- 🔴 必学：事务基础 → ACID → 隔离级别 → MVCC
- 🔴 必学：行锁（Record/Gap/Next-Key）→ 死锁排查
- 🟡 选学：乐观锁 vs 悲观锁的应用场景
- ✅ 验证：能解释"为什么我的事务没 commit，别人就看不到"和"两个事务同时更新同一行会发生什么"
- 📖 资源：`knowledge/07-transaction/`、`knowledge/08-lock/`

---

🏔️ **阶段四：数据库设计**（预计 2 周）

- 🔴 必学：ER 模型 → 范式（1NF/2NF/3NF）→ 反范式设计
- 🔴 必学：命名规范 → 常见设计模式（树形结构、多态关联）
- 🟡 选学：数据库设计工具（dbdiagram、Navicat 建模）
- ✅ 验证：给一个需求文档，能画出 ER 图并建出符合 3NF 的表结构
- 📖 资源：`knowledge/11-design/`

---

🏔️ **阶段五：生产实践**（预计 3 周）

- 🔴 必学：备份恢复（mysqldump、XtraBackup）
- 🔴 必学：主从复制 → 读写分离 → 主从延迟处理
- 🔴 必学：用户权限管理 → SQL 注入防护
- 🟡 选学：高可用方案 → 分库分表 → 数据库代理
- ✅ 验证：能搭建一主一从复制环境，写一个脚本自动备份 + 验证备份可用
- 📖 资源：`knowledge/13-replication/`、`knowledge/14-backup/`、`knowledge/15-security/`、`knowledge/16-cluster/`

---

📊 **总预估时间：12 周**（每周 8-10 小时）

🗺️ **依赖全景图**
```
SQL 基础
├── DDL（建表）          ← 依赖 SQL 基础
├── DML（增删改）        ← 依赖 SQL 基础
│   └── JOIN + 分组      ← 依赖 DML
│       └── 子查询       ← 依赖 JOIN
│
├── 索引                 ← 依赖 DDL + 查询
│   ├── EXPLAIN          ← 依赖 索引
│   ├── SQL 优化          ← 依赖 EXPLAIN
│   └── 性能调优          ← 依赖 SQL 优化
│
├── 事务                 ← 依赖 DML
│   └── 锁              ← 依赖 事务
│
└── 数据库设计           ← 依赖 索引 + 事务
    └── 生产实践         ← 依赖 全部上述内容
```

⚡ **快速启动路径**（最快 4 周开始干活）
```
SQL 基础 → DDL → DML → JOIN → 索引基础 → 事务基础 → 数据库设计基础
```
