# qzz-roadmap

**Generate structured learning roadmaps for technical domains.**

## 一句话定位

不是资源列表。是一张"不走弯路"的地图——告诉你学什么、按什么顺序、怎么才算学会了。

## 核心问题

大多数"学习路线图"只是话题的罗列。但真正的难点从来不是"有哪些东西要学"，而是：

1. **先学什么后学什么？**——A 没学就跑去看 B，看了三天发现看不懂，浪费时间。
2. **怎么才算学会了？**——"读完了"不等于"会了"，但没有标准你就不知道自己到底会不会。
3. **哪些可以跳过？**——不是所有东西都值得现在学。有时候先跳过 3 个话题开始干活，比按部就班学完更快。

qzz-roadmap 解决的就是这三个问题。

## 触发方式

在 Claude Code 中直接问：

- "我想学 MySQL，给我一个学习路线"
- "Go 语言的学习路线图"
- "想成为后端开发，需要学什么？按什么顺序？"

或者直接指定：

```
/qzz-roadmap MySQL
```

## 输出内容

每次生成路线图固定包含：

| 内容 | 说明 |
|------|------|
| 🎯 目标画像 | 走完这条路你能做什么 |
| 🏔️ 分阶段路线 | 3-5 个阶段，每阶段 3-5 个话题，标注必学/选学 |
| ✅ 验证方式 | 每个阶段有具体的"怎么算学会"标准 |
| 🗺️ 依赖全景图 | ASCII 树状图，一眼看清所有话题的依赖关系 |
| ⚡ 快速启动路径 | 砍掉所有可选的，最快能干什么 |
| 📊 时间预估 | 按每周 8-10 小时计算的总时间 |

## 和 qzz-explain 怎么配合

```
qzz-roadmap：画地图
    "学 MySQL 分三步：先理解存储结构，再学索引原理，最后搞事务"

qzz-explain：当导游
    "第三步的'事务隔离级别'具体怎么回事，我给你讲"
```

拿到 roadmap 之后，对任何一步不懂的，直接用 qzz-explain 深入。

## 与知识库的关系

生成的路线图会自动关联 `knowledge/mysql/` 目录中已有的知识：
- 已有知识（17 章 71 个概念）标注为 📖 `knowledge/mysql/<章节>/<概念>/`
- 每个概念包含 7 个文件：正文、示例、练习、常见错误、面试题、参考资料
- 缺失的重要话题标记为 "建议建设"，方便后续扩展

现有知识库覆盖范围见 `knowledge/mysql/README.md` 和 `knowledge/mysql/glossary.md`。
