# 常见错误

## 错误 1：依赖 MySQL 8.0 自动生成的自签名证书上生产

**症状**：生产环境用 MySQL 自动生成的证书。安全审计指出"自签名证书不安全——可以中间人攻击"。

**原因**：MySQL 8.0 启动时如果检测到没有 SSL 证书，会自动生成自签名证书。但这个证书不是由可信任的 CA 签发的——攻击者可以生成另一个自签名证书冒充服务器，客户端无法检测。

**怎么修**：生产环境用公司 CA 或公共 CA（如 Let's Encrypt）签发的证书。客户端配置 `--ssl-ca` 指向 CA 证书以验证服务器身份。

## 错误 2：担心性能损失而不开 SSL

**症状**：DBA 拒绝开启 SSL，理由是"加密解密会影响数据库性能"。

**原因**：十年前的数据库确实可能因为 SSL 开销掉 10-20% 性能。但现代 CPU 有硬件 AES 加速，TLS 1.3 的握手也大幅简化——SSL 额外开销通常 < 5%，绝大多数场景察觉不到。

**怎么修**：在测试环境实测有 SSL 和无 SSL 的 TPS 差异。绝大多数场景差异在可接受范围内。安全风险（明文传输密码和数据） > 性能损失。
