# 面试题

## Q1：联合索引的最左前缀原则是什么意思？

**考点**：索引领域最高频面试题。

**回答**：`INDEX(a, b, c)` 相当于创建了 `a`、`a,b`、`a,b,c` 三个索引。查询必须从最左开始，连续匹配——`b=1` 不走索引，"中间断了"也会导致后续列失效。B+Tree 按 `(a,b,c)` 整体排序——没有 a 就无法定位。

**加分**：能解释为什么 `WHERE a=1 AND c=3` 只用到了 a——中间 b 断了，c 无法使用。

## Q2：联合索引的列顺序怎么设计？

**考点**：实际设计能力，不是死记硬背。

**回答**：三个原则——等值条件在前，范围条件在后。区分度高的列放前面。经常单独查询的列放最左（它本身就是单列索引）。
