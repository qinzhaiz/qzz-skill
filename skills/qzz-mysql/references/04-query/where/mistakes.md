# 常见错误

## 错误 1：WHERE email = NULL

**症状**：`WHERE email = NULL` 永远不返回结果。

**原因**：NULL 代表"未知"——未知不等于任何东西，包括另一个未知。`NULL = NULL` 的结果是 UNKNOWN，不是 TRUE。

**怎么修**：用 `IS NULL` 和 `IS NOT NULL`。

## 错误 2：LIKE '%xxx%' 开头带 %

**症状**：数据少的时候感觉不到，数据上万之后查询突然变慢。

**原因**：LIKE 以 `%` 开头 = 前缀不确定，B+Tree 索引用不上——必须全表扫描。

**怎么修**：如果可以，避免前导通配符。如果必须模糊搜索，考虑用全文索引（FULLTEXT）或 Elasticsearch。

## 错误 3：AND/OR 不加括号

**症状**：查询返回了"不对劲"的结果——多了或少了行。

**原因**：AND 优先级高于 OR，不加括号的复杂条件会被误解。

**怎么修**：有 AND 又有 OR 时，用括号明确分组。不管 MySQL 怎么理解，你写清楚总没错。
