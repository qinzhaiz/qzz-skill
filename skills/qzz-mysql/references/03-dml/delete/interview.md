# 面试题

## Q1：DELETE 和 TRUNCATE 的区别？

**考点**：面试必问。两条清空表的命令，看起来一样，行为完全不同。

**回答**：
- DELETE 是 DML——逐行删除，条件灵活，可回滚，不重置自增
- TRUNCATE 是 DDL——整体清空，删除并重建表结构，不可回滚（隐式提交），重置自增
- 清全部数据用 TRUNCATE 更快，删部分数据用 DELETE

**加分**：能说出外键约束下的行为区别——"TRUNCATE 不能用于被外键引用的表，DELETE 可以（但可能被 ON DELETE RESTRICT 阻止）。"

## Q2：生产环境误执行了 DELETE，怎么补救？

**考点**：考察灾难恢复意识。

**回答**：如果在事务里——立刻 `ROLLBACK;`。如果 autocommit 了——用最近的备份做基于时间点的恢复（binlog 回放到 DELETE 之前的那个时间点）。如果没备份——坦率承认数据丢了，然后推动团队建立备份机制。

**加分**：提出预防措施——"开启 binlog、定期全量备份 + 增量备份、敏感操作走审批、代码 review 里任何不带 WHERE 的 DELETE 直接拒绝。"
