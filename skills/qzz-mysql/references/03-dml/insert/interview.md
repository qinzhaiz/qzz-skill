# 面试题

## Q1：INSERT 语句写列名和不写列名有什么区别？

**考点**：最基本的代码规范意识。

**回答**：写列名——`INSERT INTO t (a, b) VALUES (1, 2)`——健壮且可读。不写列名——`INSERT INTO t VALUES (1, 2)`——依赖列的物理顺序，表结构一变就崩。实际项目里必须写列名。

**加分**：能举出具体场景——"表加了新列之后不写列名的 INSERT 会报 column count mismatch。另外别人看你代码时，不写列名的 INSERT 完全猜不出哪个值对应哪个列，极度降低可维护性。"

## Q2：INSERT 和 INSERT IGNORE 的区别？

**考点**：细节——平时可能不知道，出了问题才查。

**回答**：`INSERT IGNORE` 在遇到错误（主键冲突、类型不匹配等）时转成警告而不是失败，继续执行后续插入。普通 INSERT 遇到一行出错就整条失败。适合批量导入不确定质量的数据。

**加分**：提出替代方案——"如果用 `INSERT ... ON DUPLICATE KEY UPDATE` 可以更精确地控制冲突时的行为，而不只是默默忽略。"
