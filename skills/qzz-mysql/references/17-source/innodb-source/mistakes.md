# 常见错误

## 错误 1：从 main() 开始读 InnoDB 源码

**症状**：花了一周看 MySQL 的 `main()` 函数 → 启动流程 → 插件加载 → InnoDB 初始化，还没看到任何真正想学的东西。

**原因**：InnoDB 只是 MySQL 的一个引擎插件。从 main() 开始要走几万行初始化代码才能进到 InnoDB 的业务逻辑。

**怎么修**：跳过启动流程。直接从你想了解的功能入口开始。想看 SELECT 怎么执行 → 搜 `row_search_mvcc`。想看 INSERT → 搜 `row_insert_for_mysql`。

## 错误 2：不区分 C 和 C++ 部分

**症状**：在不熟悉的 C++ 特性（模板、虚函数）上花太多时间。

**原因**：InnoDB 源码混合了 C 和 C++。核心逻辑用 C 风格写的，外层封装用了少量 C++ 特性。但关键数据结构和算法都是 C 风格。

**怎么修**：关注核心数据结构和函数实现。C++ 部分（`class ha_innobase` 等）是 MySQL Server 层的接口封装，理解大致接口就行。
