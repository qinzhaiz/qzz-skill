# 面试题

## Q1：脏读、不可重复读、幻读的区别？

**考点**：几乎必问。

**回答**：脏读——读到未提交的数据（别人改了但还没 COMMIT）。不可重复读——同一事务两次读同一行结果不同（别人改了且提交了）。幻读——同一事务两次查同一范围行数不同（别人插入或删除了行）。

**加分**：能画表——哪个级别解决哪个问题。

## Q2：为什么 MySQL 默认 RR 而不是 RC？

**考点**：历史 + 技术理解。

**回答**：MySQL 的 RR 通过 MVCC + Next-Key Lock 同时解决了不可重复读和大部分幻读——比 RC 安全性高，比 SERIALIZABLE 性能好。历史原因也有——MySQL 的 binlog 在 STATEMENT 格式下需要 RR 来保证主从一致。虽然现在 ROW 格式不再依赖隔离级别，但 RR 已经成为事实标准。
