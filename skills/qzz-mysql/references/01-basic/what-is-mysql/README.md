# MySQL 是什么

> MySQL 是世界上最流行的开源数据库管理系统（DBMS）。它是那个帮你存数据、查数据、改数据的软件。

## 为什么需要它

上一节说了"数据库是存数据的地方"。但数据不会自己把自己组织好——你需要一个专门的软件来管理它。

这个软件就是 **DBMS（数据库管理系统）**。MySQL 就是 DBMS 里用得最多的那个。

## 它是什么

MySQL 是一个**开源的关系型数据库管理系统**。拆开说：

- **开源**：免费使用，免费修改。这是它流行最核心的原因。
- **关系型**：数据存在"表"里，表和表之间通过关系（外键）连接。
- **数据库管理系统**：所有对数据的操作——存、查、改、删——都由它处理。你不直接碰数据文件，你通过 MySQL 操作。

MySQL 为什么这么流行？四个原因：

| 原因 | 说明 |
|------|------|
| **免费** | 开源，社区版零成本。个人学、小团队用、大公司在特定场景下用，都不花钱 |
| **快** | 默认引擎 InnoDB 经过 20 多年优化，读写在大多数场景下足够快 |
| **可靠** | Facebook、Google、GitHub 这些公司都在用 MySQL 处理关键数据 |
| **简单** | 几分钟装好，一条 SQL 就能开始操作 |

MySQL 有两个维度区分：

**按发行版**：
- **Community Edition**（社区版）：免费，我们学的是这个。
- **Enterprise Edition**（企业版）：付费，多了监控、备份等高级工具。

**按版本号**：推荐学习用 **8.0**。这是目前使用最广的版本，所有主流特性都有，工具兼容性最好。8.4 是 LTS（长期支持版），9.x 是 Innovation Release（创新版）。学会 8.0 后，切到 8.4 或 9.x 只需要几天。

除了 MySQL，市面上还有 PostgreSQL、Oracle、SQLite、SQL Server。它们都是 DBMS，都能通过 SQL 操作，但定位不同：

| DBMS | 特点 | 典型场景 |
|------|------|---------|
| **MySQL** | 开源、快、简单 | Web 应用、中小型系统、学习 |
| **PostgreSQL** | 开源、功能最全、标准兼容最好 | 复杂查询、地理数据、需要高级功能 |
| **SQLite** | 嵌入式、零配置、存成单文件 | 移动 App、桌面软件、原型开发 |
| **Oracle** | 商业、功能强大、贵 | 银行、金融、大型企业 |
| **SQL Server** | 微软出品、.NET 生态绑定 | 微软技术栈的企业应用 |

你不需要全学会。学好 MySQL 一个，切到其它 DBMS 只需要适应几天。

## 怎么工作

MySQL 采用**客户端-服务器**架构。

```
[客户端] ←→ 网络 ←→ [MySQL 服务器]
  ↑                      ↑
你和用户交互的软件      处理数据的那台机器
（命令行 / Workbench /   （运行 mysqld 进程）
你的 Java 程序）
```

- **服务器**：运行 `mysqld`（MySQL Daemon），负责数据存储、查询处理、权限检查。只有服务器能碰数据文件。
- **客户端**：你用来跟服务器对话的工具——命令行、MySQL Workbench、或者你的 Java/Python 程序。

你从客户端发一条 SQL，服务器处理完把结果传回来。即使客户端和服务器在同一台机器上，这个流程也一样。

## 怎么用

装好 MySQL 后（下一节），打开命令行：

```bash
mysql -u root -p
```

输入密码后，你会看到：

```
mysql>
```

这个 `mysql>` 就是 MySQL 的命令行客户端。你在这里输入的每一条 SQL，都会发给 MySQL 服务器执行。

试试看 MySQL 的版本：

```sql
SELECT VERSION();
```

## 注意事项

- **MySQL 和 MariaDB 不是同一个东西。** MariaDB 是 MySQL 的一个分支（原 MySQL 创始人担心 Oracle 收购后 MySQL 不再开源，于是另起炉灶）。很多命令通用，但不要混为一谈。
- **版本选 8.0。** 这是目前使用最广的版本，工具兼容性最好。5.7 太老，9.x 太新不适合作为学习起点。
- **Community 版足够了。** 学知识、做项目、甚至小公司上线，社区版完全够用。别被 Enterprise 版的宣传吓到。
