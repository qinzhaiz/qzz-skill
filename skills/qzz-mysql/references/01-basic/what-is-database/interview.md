# 面试题

## Q1：说一下你对数据库的理解

**考点**：不是考你背定义，是看你是不是真的用过、有没有自己的理解。

**回答**：数据库是一个有组织地存储数据的系统。它解决的核心问题是——把数据长期、安全地存下来，并支持多个人同时查、改、统计。和 Excel 最大的区别是，数据库能处理大量数据（百万行以上），支持多人同时访问而不乱，并且有事务、索引、权限这些保障机制。

**加分**：提到自己做过的一个项目里数据库怎么用的——"我做课设的时候，用户表放基础信息，订单表放交易记录，用 user_id 关联……"

## Q2：数据库、DBMS、SQL 的区别

**考点**：概念分不分的清。很多人混着说，面试官一听就知道你基础扎不扎实。

**回答**：
- **数据库**：存数据的地方。是个概念，不特指某个软件。
- **DBMS**（数据库管理系统）：管理数据库的软件。MySQL、PostgreSQL、Oracle 都是 DBMS。数据库是通过 DBMS 创建和操作的。
- **SQL**：操作数据库的语言。你写 SQL 告诉 DBMS 要查什么、改什么，DBMS 去执行。

**加分**：举一个具体场景——"我在项目里用 MySQL Workbench 连上 MySQL，然后写 SQL 建表、查数据。MySQL 是 DBMS，Workbench 是图形化客户端，我写的 CREATE TABLE 和 SELECT 是 SQL。"

## Q3：一个网站通常有哪些数据需要存数据库？

**考点**：考察你有没有想过"数据从哪来"这个问题。初级开发最容易只关注写代码，不关注数据设计。

**回答**：以电商为例——
- 用户数据：账号、密码、手机、地址
- 商品数据：名称、价格、库存、图片、分类
- 订单数据：谁买了什么、多少钱、什么状态
- 物流数据：快递单号、到哪了

**加分**：画出这些表之间的关系——"一个用户可以有多个订单（一对多），一个订单包含多个商品（多对多，需要中间表）"。
