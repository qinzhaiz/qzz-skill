# 什么是数据库

> 数据库是存放数据的地方。它不是 Excel，而是一个专门管"存、查、改、统计"的系统。

## 为什么需要它

想象你在做校园二手交易网站。用户填了用户名和手机号，点了「注册」。

如果你把这些信息存在网页变量里，服务器一重启，全没了。用户下次来登录，你拿什么验证？

**数据库存在的第一个原因：存数据。** 长期记、关机也不丢。

光存不够。用户登录要查「这个手机号注册过没有」，打开商品页要查「这件商品多少钱」，打开订单要查「我买过什么」——**第二个原因：查数据。**

数据会变。用户换手机号、商品调价、订单状态从「待付款」变「已发货」——**第三个原因：改数据和删数据。**

老师想看这个月多少订单、哪个分类商品最多——**第四个原因：统计数据。**

存、查、改、统计——这四个动作几乎覆盖你在项目里对数据库做的所有事情。

## 它是什么

**数据库**是一个以有组织的方式存储数据的集合。最好的类比是**文件柜**：一个柜子里有多个抽屉（表），每个抽屉里整齐地放着文件（数据行）。

但新手最容易混的是这三个词：**数据库、MySQL、SQL**。它们不是同一个东西。

| | 是什么 | 类比 |
|---|---|---|
| **数据库** | 存数据的地方 | 文件柜 |
| **MySQL** | 管理数据库的软件（DBMS） | 帮你整理文件柜的管理员 |
| **SQL** | 操作数据库的语言 | 你跟管理员说的话 |

确切地说，MySQL 应该叫 **DBMS（数据库管理系统）**——它是创建和管理数据库的软件。你并不直接操作数据库文件，你通过 MySQL 操作，MySQL 替你访问数据。

市面上还有 PostgreSQL、Oracle、SQLite，它们和 MySQL 做一样的事，但实现方式不同，就像不同公司的文件柜管理系统。

## 怎么工作

一个软件系统通常拆成三层：

```
页面层（用户看到的） → 程序层（处理逻辑） → 数据库层（管数据）
```

- **页面**：展示和接收操作——用户点了什么、输入了什么
- **程序**：处理逻辑——检查输入、决定查什么还是存什么
- **数据库**：管数据——存、查、改、统计

一句话：**页面负责展示，程序负责逻辑，数据库负责数据。**

你操作数据库的实际流程：

```
你自己 → SQL 语句 → MySQL（DBMS） → 数据库文件
```

你写 SQL，MySQL 执行，数据库文件被操作。你从头到尾都不直接碰文件。

## 怎么用

这个概念不需要"用"。你需要在下一节装上 MySQL，然后开始写 SQL。现在先记住这三层关系就行。

## 注意事项

- **数据库不是 Excel。** Excel 适合个人分析几百行数据；数据库适合多人同时操作几十万行数据，并且保证数据不乱。
- **MySQL 不是唯一的数据库。** 学 MySQL 是因为它用得最多，但核心概念（表、行、列、SQL）在所有数据库里都一样。学会了 MySQL，切到 PostgreSQL 只需要几天。
- **SQL 和编程语言是两回事。** Java/Python 是通用语言，SQL 只管数据库。实际项目里，你会在 Java/Python 代码里嵌入 SQL 语句。
