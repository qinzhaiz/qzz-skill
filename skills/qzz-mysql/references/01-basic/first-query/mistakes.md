# 常见错误

## 错误 1：忘了 USE 就建表

**症状**：`ERROR 1046 (3D000): No database selected`

**原因**：你没告诉 MySQL 在哪个库里操作。建表前必须先选库。

**怎么修**：`USE mysql_practice;` 然后再操作。养成习惯：连上 MySQL 后第一条就是 `USE 你的库名;`

## 错误 2：在系统库里建表

**症状**：表建在了 `mysql` 库或者别的系统库里。

**原因**：登录后没选库，默认可能在某个系统库上下文中。

**怎么修**：`SELECT DATABASE();` 确认当前在哪个库。如果是系统库或者 NULL，立刻 `USE mysql_practice;`。系统库里建的表趁早删掉——`DROP TABLE 表名;`。

## 错误 3：表名或列名用了中文

**症状**：建了 `用户` 表，查 `SELECT * FROM 用户;` 也行，但到别的系统就报错。

**原因**：虽然 MySQL 支持中文表名，但绝大多数公司和开源项目都用英文命名。

**怎么修**：表名和列名只用英文字母、数字和下划线。`user` 不是 `用户`，`created_at` 不是 `创建时间`。注释用中文没问题（`COMMENT '姓名'`）。
