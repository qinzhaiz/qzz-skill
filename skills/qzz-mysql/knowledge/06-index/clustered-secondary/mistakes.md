# 常见错误

## 错误 1：用 UUID 做主键

**症状**：写入越来越慢，磁盘碎片越来越多。

**原因**：UUID 是随机的——每次 INSERT，新行可能插入 B+Tree 中间的某个位置，导致页分裂。页分裂 = 数据页变半满，磁盘空间浪费，写入变慢。

**怎么修**：主键用自增 INT 或 BIGINT——新数据总是追加到最后，无页分裂。如果业务需要 UUID，另设一列存它，主键仍用自增。

## 错误 2：在主键上不停做范围 DELETE

**症状**：长时间运行后表中有空洞。

**原因**：删掉主键靠前的行 = 聚簇索引的 B+Tree 中出现空隙，InnoDB 不会自动回收这些页。

**怎么修**：分批删除，定期 OPTIMIZE TABLE 碎片整理（不要在生产高峰期做）。
