# 面试题

## Q1：聚簇索引和二级索引的区别？

**考点**：索引核心概念，几乎必问。

**回答**：聚簇索引叶子节点存整行数据，一张表只有一个（通常是主键）。二级索引叶子节点存主键值——查到主键后要"回表"去聚簇索引拿整行数据。二级索引可以有很多个。

**加分**：能说清楚为什么二级索引查 `SELECT *` 比只查主键慢——因为 `*` 需要回表。

## Q2：为什么建议主键用自增 INT 而不是 UUID？

**考点**：理解聚簇索引的存储特性。

**回答**：自增主键新行总在 B+Tree 末尾追加——无页分裂，写入快，空间利用率高。UUID 随机分布——新行插入可能在 B+Tree 中间——页分裂——性能下降。INT 4B vs UUID 36B——主键越小 → 每页存更多 key → 树更矮 → IO 更少。二级索引叶子节点也存主键值——小主键让所有二级索引都受益。
