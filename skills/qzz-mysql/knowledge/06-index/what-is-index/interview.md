# 面试题

## Q1：索引是什么？为什么能加速查询？

**考点**：最基础的索引概念。

**回答**：索引是一种数据结构（InnoDB 用 B+Tree），为某一列或多列建立快速查找路径。没有索引时查询要做全表扫描，逐行比对。有索引时 MySQL 可以在 B+Tree 中 O(logN) 定位到目标数据所在的页，只读少数几个页就能返回结果。

**加分**：能用"书的目录"做类比——翻目录找到页码 vs 一页页翻全书。

## Q2：索引的代价是什么？

**考点**：理解索引是权衡，不是免费的午餐。

**回答**：写入性能下降——每次 INSERT/UPDATE/DELETE 都要更新索引。存储空间增加——索引是独立的数据结构。一个表建太多索引会导致写入速度显著下降。所以索引要建在值得的列上。
