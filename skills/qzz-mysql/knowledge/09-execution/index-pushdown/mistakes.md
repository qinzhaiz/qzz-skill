# 常见错误

## 错误 1：以为加了联合索引就一定有 ICP

**症状**：建了联合索引 `(a, b)`，查 `WHERE a = 1 AND b = 2`，EXPLAIN 没有显示 `Using index condition`。

**原因**：`a = 1 AND b = 2` 两个条件都是等值查询——存储引擎一次性就定位到了精确位置，没有"先查范围再过滤"的过程。ICP 主要优化的是范围查询场景——比如 `a LIKE 'prefix%' AND b = 2`。等值查询本来就不需要 ICP。

**怎么修**：不需要修——这种查询本来效率就高。ICP 不是所有场景都需要的优化。

## 错误 2：以为 ICP 对所有查询都生效

**症状**：建了联合索引，预期 ICP 优化查询，EXPLAIN 却显示 `Using index` 或 `Using where`。

**原因**：可能的情况——(1) 查询是覆盖索引，不需要回表，ICP 不会触发（显示 `Using index`），(2) WHERE 条件的列不全在索引中，下推不了（显示 `Using where`），(3) 访问类型是 ALL（全表扫描），没有索引可用。

**怎么修**：理解 ICP 的触发条件——有索引可用、需要回表、WHERE 中有索引列能过滤掉大量数据。不满足这些条件就不要期待 ICP。
