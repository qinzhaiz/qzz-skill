# 练习

## 基础练习

1. MySQL 是开源软件，这意味着什么？对你有什么好处？

2. "MySQL 是客户端-服务器架构"——用你自己的话解释这是什么意思。

3. 查一下你电脑上装的 MySQL 版本号（如果还没装，先看下一节后再回来做）。

## 进阶练习

1. 除了 MySQL，你还听说过哪些数据库？查一下它们各自用在什么场景——哪些公司、什么业务。

2. 一个网站从 100 个用户增长到 100 万个用户，MySQL 能一直扛住吗？如果不能，通常怎么做？（这个问题暂时不要求准确回答，只是为你后面的学习留个印象。学到 16-cluster 时回来再看。）

## 答案

1. 开源意味着你可以免费下载使用，有权限阅读源码、修改源码。最大的好处是零成本入门，学 MySQL 不用买许可。

2. MySQL 分为服务器和客户端两部分。服务器是真正处理数据的那一端，只有它能访问数据文件。客户端是你用来发 SQL 的工具（命令行、Workbench、Java 程序）。你从客户端发请求，服务器处理后返回结果。即使它们在同一台电脑上，这个通信过程也是一样的。

3. 安装 MySQL 后运行 `SELECT VERSION();` 即可查看。
