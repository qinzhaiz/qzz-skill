# 练习

## 基础练习

1. 用你自己的话解释：数据库、MySQL、SQL 三个词分别是什么，它们之间什么关系。

2. 想一个你熟悉的 App（微信、淘宝、B站……），说出它至少 3 类需要存进数据库的数据。
   - 例如：B站 — 用户信息、视频信息、评论、关注关系

## 进阶练习

1. "页面负责展示，程序负责逻辑，数据库负责数据"——以你常用的一个功能为例（比如淘宝下单），画出数据在三层之间怎么流动的。

2. 你平时用 Excel 做过哪些事？哪些场景用数据库比 Excel 更好？为什么？

## 答案

1. 数据库是存数据的地方（文件柜），MySQL 是管理数据库的软件（管理员），SQL 是操作数据库的语言（你和管理员说的话）。数据库是概念，MySQL 是具体的软件（DBMS），SQL 是你和 MySQL 沟通的语言。

2. 开放题，无标准答案。以淘宝为例：用户信息（用户名、手机、地址）、商品信息（名称、价格、库存、图片）、订单信息（谁买了什么、什么状态、多少钱）、物流信息（快递单号、到哪了）。
