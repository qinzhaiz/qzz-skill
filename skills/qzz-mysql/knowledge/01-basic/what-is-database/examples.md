# 代码示例

> 第一个概念不需要写代码——数据库是一个概念，不是一条 SQL。
> 但你可以提前看一眼接下来会写的东西长什么样。

## 示例 1：一条最简单的 SQL

```sql
SELECT * FROM users;
```sql

这条 SQL 对 MySQL 说："把 users 表里的所有数据查出来给我。"

- `SELECT` = 查
- `*` = 所有列
- `FROM users` = 从 users 这张表里查
- `;` = 语句结束

你后面会反复写这一行，现在只需要知道它长这样就行。

## 示例 2：一个最简单的表长什么样

```sql
users 表：
+----+----------+-------------+
| id | name     | phone       |
+----+----------+-------------+
| 1  | 张三     | 13800001111 |
| 2  | 李四     | 13900002222 |
+----+----------+-------------+
```sql

- 每一行是一个用户
- 每一列是一种信息（id、姓名、手机号）
- `id` 是主键——每条数据的唯一标识，绝不重复

## 示例 3：数据库在项目里的角色

```sql
[浏览器] 用户点「注册」，填了姓名和手机号
    ↓
[程序] 检查手机号格式对不对
    ↓
[程序] 发 SQL 给 MySQL：「把这个用户存进 users 表」
    ↓
[MySQL] 收到 INSERT 语句 → 写入数据文件 → 返回「存好了」
    ↓
[程序] 告诉浏览器：「注册成功」
```sql

整个过程，用户看不见数据库这一层，但数据库在下面做了最关键的事——把数据永久保存下来。
