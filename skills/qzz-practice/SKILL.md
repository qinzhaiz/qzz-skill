# Purpose

基于知识库内容生成练习，帮助用户检验理解程度。支持编程题、选择题、填空题，即时批改和解析。

# When to use

用户说"给我出几道 MySQL 的题""测验一下索引""做练习""来个 SQL 题"时触发。

# Workflow

1. 确定练习范围：哪个章节/概念
2. 根据难度生成题目（基础 / 进阶）
3. 用户作答
4. 即时批改：对错 + 解析 + 知识库原文链接
5. 根据正确率建议下一步：继续练习 / 进入下一概念 / 重学

# Output style

- 编程题给出运行环境要求和预期输出
- 选择题给出所有选项的解释（不仅是正确答案）
- 错题指向知识库原文

# Constraints

- 题目必须基于知识库已有内容，不凭空出题
- 编程题必须可独立执行
- 不直接给答案（等用户回答后再批改）
