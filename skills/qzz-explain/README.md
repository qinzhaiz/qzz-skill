# qzz-explain

**不只是解释"是什么"，是让你产生"原来如此"的顿悟。**

## 它解决什么问题

大多数技术讲解的问题不是信息不够，而是**没有让人"click"**。

你肯定有过这种体验：看了五篇文章都没搞懂，突然有个人说了一句话你就通了。那一句话往往不是更详细的定义——而是一个对的类比、一个设计视角的转换、或者一个"你其实已经懂了 A，而 B 就是 A 的另一种形态"的连接。

qzz-explain 做的事情就是系统化地制造这种"click 时刻"。

## 三种模式

根据你的问题自动选择：

| 模式 | 适合场景 | 输出 |
|------|---------|------|
| 速览 | "X 是什么？" 快速了解 | 一段话 + 一个类比 + 一段代码 |
| 深讲 | "我想真正搞懂 X" | 痛苦→设计→机制，附类比/代码/边界/连接 |
| 纠错 | 你卡住了，或者理解偏了 | 定位误解根源 → 精准修正 → 反例验证 |

## 触发方式

直接问就行：

- "什么是覆盖索引？"→ 速览
- "我想深入理解 MySQL 的事务隔离级别"→ 深讲
- "我理解的 MVCC 是这样的……对吗？"→ 纠错
- "/qzz-explain B+Tree"→ 默认速览，你决定是否深入

## 和 qzz-roadmap 配合

```
roadmap：告诉你学什么、按什么顺序
explain：带你深入路线上每一个点
```

在 roadmap 的某个阶段中触发的 explain，会自动关联你在路线上的位置。

## 讲解可以保存

每次深讲结束后，可以选择把讲解保存到 `knowledge/mysql/` 知识库。保存格式与现有知识库一致：
- 路径：`knowledge/mysql/<章节>/<概念名>/README.md`
- 每个概念 7 个文件：README.md / metadata.yaml / examples.md / exercises.md / mistakes.md / interview.md / references.md

现有知识库已覆盖 17 章 71 个概念（详见 `knowledge/mysql/README.md`）。
