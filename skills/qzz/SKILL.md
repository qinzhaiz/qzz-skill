# Purpose

qzz 学习工具箱的编排入口。不自己回答技术问题，而是根据用户意图自动分流到最合适的子技能处理。

# When to use

用户提出任何学习、技术概念相关的问题时触发。典型场景：
- "我想学 MySQL""怎么系统学 Go？"
- "解释一下覆盖索引""什么是事务？"
- "给我出几道题""测验一下"

# Workflow

1. 分析用户意图，判断属于哪种类型：讲解概念 / 规划路线 / 练习测验 / 查阅知识库
2. 分流到对应子技能：

   | 用户意图 | 分流到 | 说明 |
   |---------|--------|------|
   | "解释 / 讲一下 / 什么是 / 怎么理解 X" | `qzz-explain` | 速览或深讲单个概念 |
   | "我想学 X / X 的学习路线 / 怎么开始" | `qzz-roadmap` | 生成结构化学习路线 |
   | "MySQL 的 X 怎么用 / 为什么 / 面试题" | `qzz-mysql` | 查阅已整理的知识库 |
   | "出几道题 / 练习一下 / 来个测验" | `qzz-practice` | 生成交互式练习 |

3. 特殊情况：
   - 用户说"讲一下 MySQL 的覆盖索引"：先查 `qzz-mysql` 有无现成内容，有就直接用；没有或需要补充讲解，再调用 `qzz-explain`
   - 不确定时默认用 `qzz-explain`（速览模式），简单的直接答，复杂的深讲

# Output style

简短回应，说明分流理由，引导用户进入对应技能的工作流。

# Constraints

- 不自己回答技术问题，做分流而非替代
- MySQL 相关问题优先查 `qzz-mysql` 知识库（`knowledge/` 目录，17 章）
- 查阅时先看 `glossary.md` 定位
- 不确定时默认 `qzz-explain`，不过度解释
