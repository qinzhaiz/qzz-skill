# 面试题

## Q1：PRIMARY KEY 和 UNIQUE 的区别？

**考点**：主键和唯一键是最基本的概念区分，几乎必问。

**回答**：两者都要求值不重复，但 PRIMARY KEY 一张表只能有一个，且不能包含 NULL。UNIQUE 一张表可以有多个，且可以包含 NULL（但每列只能有一行 NULL）。另外，InnoDB 用主键组织数据——主键的选择直接影响存储和查询性能。

**加分**：能说出"主键是物理概念（决定数据怎么存），唯一键是逻辑概念（保证业务规则）"。

## Q2：CHAR 和 VARCHAR 的区别？

**考点**：字符串存储是最常用的数据类型选择。

**回答**：CHAR 定长——不管实际内容多长都占固定空间，取数据时不需要计算长度所以略快。VARCHAR 变长——只占实际内容的空间加 1-2 字节存长度，更省空间。大部分场景用 VARCHAR，只有长度绝对固定（如手机号、MD5、状态码）才用 CHAR。

**加分**：能说出 UPDATE 频繁的列优先用 VARCHAR——CHAR 的定长优势在更新时反而可能触发页分裂。
