# 练习

## 基础练习

1. 往 user 表插一条测试数据，然后用 DELETE 删掉它。

2. 插 3 条测试数据，用 `DELETE FROM user WHERE id IN (x, y, z)` 一次删掉。

3. **在测试库里跑一次不带 WHERE 的 DELETE，然后用 SELECT 看看发生了什么。**

## 进阶练习

1. 建一张临时表，插 5 条数据。先用 DELETE 清空，再插一条看看自增 id。然后 TRUNCATE，再插一条对比。

2. 用分批删除的方式，每次 LIMIT 2，清空一张 10 行的表。

## 答案

1-3 无标准答案。第 3 题教训：整张表全空了。
