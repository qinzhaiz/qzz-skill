# 常见错误

## 错误 1：每列都建索引

**症状**：表上 10 列，建了 8 个单列索引。写入变得极慢。

**原因**：以为"索引越多查询越快"——忽略了写入成本。每次 INSERT 都要更新所有索引。

**怎么修**：只为高频查询的列建索引，关注 EXPLAIN 结果，删除未使用的索引。

## 错误 2：以为 EXPLAIN key 为 NULL 就是没走索引

**症状**：看到 `key: NULL` 就认为"索引没起作用"。

**原因**：小表或覆盖不到的情况下，优化器可能认为全表扫更快。几千行的表全表扫可能真的比走索引快。

**怎么修**：关注 `rows` 列——预估扫描行数。大表 rows 很高且 key 为 NULL → 该建索引了。

## 错误 3：索引建了但查询没用上

**症状**：明明建了索引，查询 WHERE 条件正好是索引列，EXPLAIN 却显示全表扫。

**原因**：在索引列上用了函数（`WHERE YEAR(date_col) = 2025`）或者发生了隐式类型转换。

**怎么修**：避免在 WHERE 中对索引列做运算或函数调用。
