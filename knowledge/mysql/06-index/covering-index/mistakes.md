# 常见错误

## 错误 1：为了覆盖索引把所有列塞进去

**症状**：10 列联合索引——只用到一个 WHERE 条件，其余 9 列都是"覆盖列"。

**原因**：过度追求覆盖索引——忽略了索引维护成本和内存占用。

**怎么修**：覆盖索引只覆盖高频查询的关键列——经常一起查、返回列少的查询。不要试图用一个索引覆盖所有场景。

## 错误 2：覆盖了但索引列顺序不对

**症状**：覆盖列放在 WHERE 列前面——索引用不上。

**原因**：违反了最左前缀原则。覆盖索引也是联合索引——WHERE/ORDER BY 列必须排在覆盖列之前。

**怎么修**：索引列顺序 = WHERE 列 → ORDER BY 列 → 覆盖列。等值在前，范围在后，覆盖列垫底。
