# 面试题

## Q1：覆盖索引是什么？什么场景下用它？

**考点**：索引优化最重要的概念之一。

**回答**：覆盖索引就是索引本身包含了查询所需的所有列——不需要回表。EXPLAIN 的 Extra 列显示 `Using index` 就表示覆盖了。适合 SELECT 列少、WHERE 条件明确的高频查询——用最少的回表次数换取最快的响应。

## Q2：为什么 SELECT * 不好？从索引角度解释。

**考点**：SELECT * 不仅慢，还让你享受不到索引优化。

**回答**：SELECT * 需要所有列——而索引只包含有限的列，永远无法覆盖。即使用了索引，每次查询都要回表——多一次磁盘 IO。明确列名后，高频查询可以通过覆盖索引避免回表。在 1000 万行的大表上，这可能是几十 ms 和几秒的差距。
