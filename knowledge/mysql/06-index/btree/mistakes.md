# 常见错误

## 错误 1：以为 B+Tree 存储的是"行指针"

**症状**："索引存的是指向数据行的指针"。

**原因**：这是 SQL Server 的行为，不是 InnoDB 的。InnoDB 的聚簇索引叶子节点存的是整行数据，不是指针。

**怎么修**：记住 InnoDB 的聚簇索引 = 表数据本身。二级索引的叶子节点存的才是"指针"（主键值）。

## 错误 2：以为主键越小越好，于是用 TINYINT

**症状**：主键设成了 TINYINT（上限 127），数据增长后溢出。

**原因**：只考虑了"主键小 = 省空间"，忽略了数据增长。

**怎么修**：主键用 INT UNSIGNED（42 亿上限）。只有确定数据不增长的场景（如配置表）才用更小的类型。
