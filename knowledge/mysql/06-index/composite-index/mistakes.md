# 常见错误

## 错误 1：范围条件放前面

**症状**：`INDEX(age, city)`，查询 `WHERE age > 20 AND city = '北京'`——索引用上了但只到 age。

**原因**：范围条件之后用不上索引。age 先匹配 → age 是范围 → city 失效。

**怎么修**：等值条件放前面，范围条件放后面——`INDEX(city, age)`。

## 错误 2：以为索引列顺序和查询条件书写顺序必须一致

**症状**：查询写成 `WHERE b = 2 AND a = 1`，以为走不了 `INDEX(a, b)`。

**原因**：MySQL 优化器会自动调整 WHERE 条件顺序以匹配索引——和书写顺序无关。

**怎么修**：优化器帮你处理了。你自己建索引时关注列顺序，而不是查询中的书写顺序。

## 错误 3：联合索引列太多

**症状**：7 列联合索引——每次 INSERT 维护成本极高。

**原因**：为了"覆盖所有查询"把所有列全部塞进一个联合索引。

**怎么修**：联合索引 3-4 列上限。更多的查询用多个单列索引或通过改写 SQL 优化。
