# 练习

## 基础练习

1. 用 EXPLAIN 看一个没加索引的查询，记下 rows。给 WHERE 列加索引后再看 rows。

2. 查出你的库里有没有从未用过的索引。

## 进阶练习

1. 为什么小表（几百行）有时全表扫比走索引更快？用 EXPAIN 验证。

## 答案

1. 无标准答案——rows 大幅减少就对了。

2. `SELECT * FROM sys.schema_unused_indexes;`

3. 小表全表扫 = 一次顺序 IO 读完所有页。走索引 = 查 B+Tree（2-3 次随机 IO）+ 回表（随机 IO）。小表全表扫可能更快。优化器会根据统计信息自动选择。
