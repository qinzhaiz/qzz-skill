# 常见错误

## 错误 1：以为 MySQL 是唯一的选择

**症状**：学了 MySQL 就以为所有数据库都长这样。

**原因**：大学教材和面试都围绕 MySQL，没见过别的。

**怎么修**：MySQL 学会后，花两天试试 PostgreSQL。你会发现 SQL 几乎一样，但索引、事务、扩展功能的实现方式有差异。面试时能说出"MySQL 和 PostgreSQL 在这个问题上做法不同"是很大的加分。

## 错误 2：把客户端和服务器搞混

**症状**："我装了个 MySQL Workbench，这就是 MySQL 吧？"

**原因**：图形化工具的便利让人误以为它就是数据库本身。

**怎么修**：MySQL Workbench 只是**客户端**——一个用来连接 MySQL 服务器、方便你管理数据库的图形化工具。真正的 MySQL 是 `mysqld` 进程在后台运行。Workbench 不装也可以，你可以只用命令行。区分方法是：所有执行 SQL 和存储数据的逻辑在服务器端，客户端只负责显示和交互。

## 错误 3：选错版本

**症状**：装了 MySQL 5.7 然后发现窗口函数不能用，或者装了 9.0 发现某些工具不兼容。

**原因**：不知道 MySQL 的版本路线。

**怎么修**：学习选 **8.0**。这是目前使用最广泛的版本，所有主流特性（窗口函数、CTE、JSON 支持）都有，工具兼容性最好。5.7 在 2023 年已停止支持，很多新特性缺失。8.0 是最稳的起点，学会后切到 8.4 或 9.x 都只需要适应几天。
