# 面试题

安装操作通常不会直接出现在面试中，但以下问题面试官可能顺带问。

## Q1：你用的 MySQL 是什么版本？为什么选这个版本？

**考点**：看你是不是随便装的，还是经过思考选的。

**回答**：我用的 8.0。这是目前使用最广的版本，工具兼容性最好。5.7 已经停止支持缺少窗口函数等新特性，8.4 是 LTS 版功能和 8.0 差异不大，9.x 是创新版不太适合作为学习起点。

**加分**：能说出 8.0 相比 5.7 的关键改进——窗口函数、CTE、JSON 支持、角色管理、原子 DDL。

## Q2：怎么连上一台远程 MySQL 服务器？

**考点**：考你有没有做过开发部署。很多人在本地玩得转，一连远程就卡。

**回答**：`mysql -u username -p -h 远程IP -P 3306`。需要在远程服务器上创建了允许从我的 IP 连接的用户（`CREATE USER 'xxx'@'我的IP'`），并且服务器防火墙开放了 3306 端口。

**加分**：提到生产环境通常不直接暴露 3306 端口——通过 SSH 隧道、VPN 或跳板机连接，或者应用通过内网访问数据库，不对外网开放。
