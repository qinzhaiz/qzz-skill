# 常见错误

## 错误 1：把数据库当成 Excel 用

**症状**：所有数据放一张表，几十个列随便加，想查什么就 `SELECT *` 然后在程序里过滤。

**原因**：习惯了 Excel 的自由格式，不了解数据库的设计规则。

**怎么修**：后面学到 [11-design/normalization/](../../11-design/normalization/) 和 [02-ddl/create-table/](../../02-ddl/create-table/) 就会知道，数据库讲究**分表**和**约束**——每种数据放对表、每列指定类型、关系用外键表达。这前期看起来"麻烦"，但当数据量上万后，分表和索引是救命的东西。

## 错误 2：分不清数据库和 DBMS

**症状**："我学的是数据库 MySQL"。

**原因**：MySQL 太有名了，很多人以为 MySQL = 数据库的全部。

**怎么修**：MySQL 是一种 **DBMS（数据库管理系统）**，是管理数据库的软件。换个 DBMS（PostgreSQL、Oracle），数据库的概念和 SQL 还是那套东西，只是软件不同。面试时说清楚"数据库是概念"和"MySQL 是具体产品"。

## 错误 3：在程序里用循环逐条查数据库

**症状**：查 100 个用户的详情，写一个 for 循环，每次循环发一条 SQL。

**原因**：把数据库当成本地文件——以为查一次和查一百次的成本一样。

**怎么修**：数据库是远程服务，每条 SQL 都要走网络。循环 100 次 = 100 次网络往返。学会用 `WHERE id IN (1,2,3...)` 或 JOIN 一次搞定。后面学到 [04-query/join/](../../04-query/join/) 时重点注意。
