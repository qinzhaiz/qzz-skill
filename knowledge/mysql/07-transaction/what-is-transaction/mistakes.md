# 常见错误

## 错误 1：忘了 BEGIN

**症状**：以为在事务里操作，其实是自动提交——出错了没法回滚。

**原因**：MySQL 默认 `autocommit=ON`——每条 SQL 独立提交。

**怎么修**：需要事务保护的操作用 `BEGIN` 显式开启。

## 错误 2：在事务里调用外部服务

**症状**：BEGIN 后发了一条 HTTP 请求，等 30 秒超时——事务一直不提交，锁一直不释放。

**原因**：事务持有行锁直到 COMMIT/ROLLBACK。中间加了外部调用 = 锁持有时间不可控。

**怎么修**：事务应该是最短的可能时间——发 HTTP、发消息、写文件都在事务外做。

## 错误 3：事务太大

**症状**：一个事务包含了几千条 SQL，跑了 5 分钟才 COMMIT。

**原因**：把"整个业务流程"当成一个事务。

**怎么修**：拆分大事务为小事务。一个大事务 = 大量行锁长时间持有 + undo log 膨胀 + 主从延迟。
