# 常见错误

## 错误 1：用 MyISAM 表却以为有事务保护

**症状**：写了 BEGIN...ROLLBACK，但数据被改了。

**原因**：MyISAM 不支持事务——所有操作都是 autocommit 行为。

**怎么修**：需要事务的表用 InnoDB。`SHOW CREATE TABLE` 确认引擎。

## 错误 2：把一致性当成数据库的责任

**症状**：业务逻辑有 bug 导致数据不一致，然后说"数据库应该保证一致性"。

**原因**：一致性大部分由约束（PK、FK、NOT NULL）保障——但"用户余额不能为负"这种业务规则是应用层的责任。

**怎么修**：在应用层加业务校验。数据库的约束是第一道防线，不是唯一防线。
