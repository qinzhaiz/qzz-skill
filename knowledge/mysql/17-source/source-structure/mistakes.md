# 常见错误

## 错误 1：试图从头到尾读懂所有源码

**症状**：从 main() 函数开始逐行读，三周后还在看启动流程，完全放弃。

**原因**：MySQL 源码约 300 万行，没有人能全部读懂。逐行读是最低效的方式。

**怎么修**：以问题驱动——先想清楚要理解什么（如"B+Tree 页分裂怎么实现"），然后直接搜相关函数，从那个函数开始读。只读和问题相关的代码路径。

## 错误 2：不区分 Server 层和存储引擎层

**症状**：在 InnoDB 源码中找 SQL 解析逻辑，或在 Server 层找 Buffer Pool 实现——方向完全错了。

**原因**：MySQL 的 Server 层和存储引擎层是分离的。不理解这个架构，读源码会迷失。

**怎么修**：先记住两大类目录——`sql/`（Server 层）和 `storage/innobase/`（InnoDB 引擎层）。Server 层处理 SQL 解析、优化、执行；InnoDB 层处理数据存储、索引、事务。跨层交互通过 `handler` 接口。
