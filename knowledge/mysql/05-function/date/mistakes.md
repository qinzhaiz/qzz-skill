# 常见错误

## 错误 1：WHERE 里对日期列用函数

**症状**：`WHERE DATE(created_at) = '2025-07-25'` 不能走索引，大表慢。

**原因**：对列用函数 = 索引失效。MySQL 必须先对每行取值算函数，再做比较。

**怎么修**：改成范围查询 `WHERE created_at >= '...' AND created_at < '...'`。

## 错误 2：用 2 位年份

**症状**：`WHERE created_at < '25-01-01'` 的解析结果可能不是你预期的。

**原因**：MySQL 对 2 位年份的解析规则复杂且可能随版本变化。

**怎么修**：始终用 4 位年份：`'2025-01-01'`。

## 错误 3：TIMESTAMP 的 2038 问题

**症状**：存 `2039-01-01` 到 TIMESTAMP 列报错。

**原因**：TIMESTAMP 是 32 位的，只能存 1970-2038。

**怎么修**：新项目直接用 DATETIME。
