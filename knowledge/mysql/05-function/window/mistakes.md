# 常见错误

## 错误 1：在 WHERE 里用窗口函数

**症状**：窗口函数用在了 WHERE 或 HAVING 中，报错。

**原因**：窗口函数在 SELECT 和 ORDER BY 之后执行——WHERE 看不到窗口函数的结果。

**怎么修**：用子查询包装——外层 WHERE 引用内层窗口函数的结果。

## 错误 2：PARTITION BY 和 GROUP BY 混用

**症状**：在 GROUP BY 查询里加窗口函数，结果和预期不一样。

**原因**：GROUP BY 折叠行，窗口函数在折叠后的结果上计算。

**怎么修**：需要不折叠行的分组计算 → 用窗口函数 + PARTITION BY，去掉 GROUP BY。

## 错误 3：5.7 上没有窗口函数

**症状**：在 MySQL 5.7 上执行窗口函数报语法错误。

**原因**：窗口函数是 8.0 的新特性。

**怎么修**：升级到 8.0，或者用子查询 + 变量模拟（不推荐）。
