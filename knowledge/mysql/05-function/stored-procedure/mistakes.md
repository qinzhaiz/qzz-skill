# 常见错误

## 错误 1：DELIMITER 用错

**症状**：在命令行创建存储过程时报语法错误。

**原因**：存储过程体内有分号——MySQL 会把第一个分号当结束符。需要用 DELIMITER 临时改结束符。

**怎么修**：`DELIMITER //` 把结束符改成 `//`，创建完 `DELIMITER ;` 改回来。注意 DELIMITER 是 mysql 客户端命令，不是 SQL，只能在命令行里用。

## 错误 2：变量声明位置错误

**症状**：`DECLARE cnt INT DEFAULT 0;` 报错。

**原因**：DECLARE 必须在 BEGIN 之后、第一条可执行语句之前。

**怎么修**：所有 DECLARE 放在 BEGIN 之后的最前面。

## 错误 3：用存储过程替代应用层逻辑

**症状**：复杂业务逻辑全写成存储过程，导致数据库难以扩展、代码难以维护。

**原因**：没分清"数据库该做什么"和"应用层该做什么"。

**怎么修**：数据库负责存储和查询。复杂业务逻辑放应用层——那里有 git、CI/CD、单元测试、更容易水平扩展。
