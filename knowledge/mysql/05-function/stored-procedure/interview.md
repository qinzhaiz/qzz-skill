# 面试题

## Q1：存储过程的优缺点？

**考点**：不是考你怎么写，是考你"什么时候该用、什么时候不该用"。

**回答**：优点——减少网络往返、封装可复用逻辑、权限控制更细。缺点——调试困难、没有版本管理、数据库成为瓶颈。现代 Web 开发倾向在应用层处理业务逻辑，存储过程更多用于数据迁移、定时任务、批量操作等数据库内部场景。

## Q2：存储过程和函数的区别？

**考点**：MySQL 基础对象区分。

**回答**：存储过程用 `CALL` 执行，可以有 IN/OUT 参数，内部可以写事务控制。函数用 `SELECT` 调用，必须有返回值，不能在函数内执行 COMMIT/ROLLBACK。
