# 面试题

## Q1：SELECT * 和 SELECT 列名有什么区别？

**考点**：看你是不是有代码规范意识。

**回答**：`SELECT *` 查所有列——方便但危险。`SELECT 列名` 只查需要的列——更快、更省内存、更不受表结构变更影响。生产代码里必须写列名。

**加分**：举出具体伤害——"表加了 TEXT 字段后，一个 `SELECT *` 的接口从 50ms 变成 3s。排查了半天才发现是多取了一个大字段。从那之后 lint 规则里 `SELECT *` 直接不给过。"

## Q2：LIMIT 10 和 LIMIT 10 OFFSET 100000 哪个快？

**考点**：理解 LIMIT 不是魔法——大偏移量还是要扫很多数据。

**回答**：LIMIT 10 只扫 10 行就停——快。LIMIT 10 OFFSET 100000 要扫前 100000 行再返回 10 行——慢。OFFSET 越大越慢。优化方案是用"游标分页"——`WHERE id > 上一页最后一条的id ORDER BY id LIMIT 10`。
