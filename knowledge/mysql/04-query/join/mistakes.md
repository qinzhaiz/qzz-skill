# 常见错误

## 错误 1：被驱动表 JOIN 字段没建索引

**症状**：数据量小时感觉不到，上万行后 JOIN 突然极慢。

**原因**：被驱动表每次关联都做全表扫描。N 行驱动表 → N 次全表扫描被驱动表。

**怎么修**：JOIN 的关联字段（通常是外键）必须建索引。这是 JOIN 优化的第一条规则。

## 错误 2：LEFT JOIN 的过滤条件放在 WHERE 里

**症状**：`LEFT JOIN ... WHERE right.id > 5`——结果和 INNER JOIN 一样了。

**原因**：WHERE 在连接完成后过滤，NULL 行也被过滤掉了。

**怎么修**：如果过滤条件属于连接逻辑——放 ON 里。如果属于结果过滤——放 WHERE 里。关键是理解 ON 和 WHERE 的执行时机差异。

## 错误 3：JOIN 太多表

**症状**：一条 SQL 连了 8 张表，自己一周后看不懂。

**原因**：过度依赖 JOIN，把本该在业务层分步处理的数据整合全扔给数据库。

**怎么修**：JOIN 不超过 3-5 张表。超过就考虑拆步骤——先查主要数据，再在应用层补信息或分批查。
