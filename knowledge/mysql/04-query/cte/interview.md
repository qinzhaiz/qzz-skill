# 面试题

## Q1：CTE 和子查询有什么区别？

**考点**：MySQL 8.0 特性 + 代码可读性意识。

**回答**：CTE 最大的优势是可读性——给子查询起个名，多步骤查询可以像搭积木一样一层层写。另外 CTE 可以多次引用、支持递归。功能上大部分 CTE 等价于子查询，但 CTE 更好维护。

**加分**：能说出"CTE 是内联展开的，每次引用重新执行，不是你期待的临时表。如果需要缓存中间结果，用临时表。"

## Q2：什么时候用递归 CTE？

**考点**：考察是否理解树形数据处理。

**回答**：递归 CTE 处理树形结构——组织架构、分类层级、评论嵌套、菜单树。不需要在应用层做多次数据库查询来逐层展开——一条 SQL 递归到底。
