## 分阶段详解

### 第一阶段：能上手（01–05，26 个概念）

学会独立操作单表增删改查。

| 章 | 概念 |
|----|------|
| 01 基础 | 数据库是什么 → 安装 MySQL → 客户端工具 → 第一条 SELECT |
| 02 DDL | 建库 → 建表 → 数据类型 → 约束（主键、外键、唯一） → 修改表结构 |
| 03 DML | INSERT → UPDATE → DELETE |
| 04 查询 | SELECT 基础 → WHERE 条件 → 排序分页 → JOIN → 子查询 → GROUP BY → UNION → CTE |
| 05 函数 | 聚合函数 → 字符串函数 → 日期函数 → 窗口函数 → 条件函数 → 存储过程 |

**前置依赖**：无（从零开始）

**学完能做**：独立建表、写增删改查、用 JOIN 查多表、写基本的聚合统计。

---

### 第二阶段：懂原理（06–10，22 个概念）

理解数据库底层怎么工作——为什么快、为什么慢、怎么修。

| 章 | 概念 |
|----|------|
| 06 索引 | B+Tree 原理 → 聚簇与二级索引 → 联合索引 → 覆盖索引 → 索引策略 → 全文索引 |
| 07 事务 | 事务基础 → ACID → 隔离级别 → MVCC |
| 08 锁 | 表锁 → 行锁（Record/Gap/Next-Key） → 死锁 → 乐观锁与悲观锁 |
| 09 执行 | SQL 生命周期 → 索引下推（ICP） → redo/undo log → 两阶段提交 |
| 10 优化 | EXPLAIN → 慢查询日志 → SQL 优化 → 配置调优 |

**前置依赖**：第一阶段（需要会写 SQL 才能理解索引和优化）

**学完能做**：看懂 EXPLAIN、优化慢 SQL、理解事务隔离级别、知道锁的类型和用途。

---

### 第三阶段：会设计（11–12，8 个概念）

从"写 SQL"升级到"设计数据库"。

| 章 | 概念 |
|----|------|
| 11 设计 | ER 模型 → 范式（1NF/2NF/3NF） → 命名规范 → 常见设计模式 |
| 12 引擎 | InnoDB 架构 → Buffer Pool → Change Buffer → MyISAM 对比 |

**前置依赖**：第二阶段（需要理解索引才能设计好的表结构）

**学完能做**：画 ER 图、设计合规的表结构、理解 InnoDB 内部架构。

---

### 第四阶段：能运维（13–16，12 个概念）

管好生产环境的 MySQL。

| 章 | 概念 |
|----|------|
| 13 复制 | 主从搭建 → 读写分离 → 主从延迟与并行复制 |
| 14 备份 | mysqldump → XtraBackup → 时间点恢复 |
| 15 安全 | 用户权限管理 → SQL 注入防护 → SSL/TLS 加密 |
| 16 集群 | 高可用架构 → 数据库代理 → 分库分表 |

**前置依赖**：第二、三阶段（需要理解 binlog、事务、InnoDB 才能搞复制和备份）

**学完能做**：搭建主从复制、做备份恢复、配置读写分离、处理安全问题。

---

### 第五阶段：看源码（17，3 个概念）

知道 MySQL 里面到底怎么实现的。

| 章 | 概念 |
|----|------|
| 17 源码 | 源码目录结构 → InnoDB 源码导读 → 编译与调试 |

**前置依赖**：前四个阶段全部

**学完能做**：编译 MySQL、用 GDB 调试、阅读 InnoDB 核心代码。

## 快速路径

如果时间有限，按以下优先级：

1. **必学**（找工作面试必备）：01-basic → 02-ddl → 03-dml → 04-query → 06-index → 07-transaction → 08-lock → 10-performance
2. **建议学**（实际工作常用）：05-function → 09-execution → 11-design → 12-engine
3. **运维方向**：13-replication → 14-backup → 15-security → 16-cluster
4. **深入方向**：17-source
