# 面试题

## Q1：一条 SELECT 语句在 MySQL 内部是怎么执行的？

**考点**：不是背流程，是理解每个组件的作用和它们之间的关系。

**回答**：MySQL 分为 Server 层和存储引擎层。Server 层有四个核心组件：连接器（建立连接、验证身份、读权限）、分析器（词法+语法分析，构建语法树）、优化器（选索引、定 JOIN 顺序、生成执行计划）、执行器（检查权限、调用引擎接口取数据）。然后存储引擎层负责实际的数据读写——InnoDB 从内存 buffer pool 或磁盘中读取数据返回。

**加分点**：能说出查询缓存被 8.0 删除的原因——表一更新整个缓存失效，命中率低。能说出 Server 层和引擎层解耦的好处——不同引擎（InnoDB、MyISAM）共用同样的 Server 层逻辑。

## Q2：EXPLAIN 有什么用？关键字段怎么读？

**考点**：日常开发工具，不是理论。

**回答**：EXPLAIN 显示优化器选择的执行计划。关键字段：`type`（访问方式，const > ref > range > ALL 从快到慢）、`key`（实际使用的索引）、`rows`（预估扫描行数）、`Extra`（额外信息——`Using index` 表示覆盖索引，`Using filesort` 表示需要额外排序，`Using temporary` 表示用了临时表）。这三个 `Using` 通常是有优化空间的信号。

**加分点**：能说出 EXPLAIN FORMAT=JSON 提供了更详细的代价评估。能提到 optimizer_trace 查看优化器为什么选择了某个索引。
